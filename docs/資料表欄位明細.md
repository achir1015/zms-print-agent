# 資料助秘3D列印AI代理人工具：資料表欄位明細

（本檔由 tools/gen_schema_doc.py 依 pa/schema.py 自動產生）

## sys_meta　系統參數

| 欄位 | 型別 | 說明 |
|---|---|---|
| k | VARCHAR(40) NOT NULL PRIMARY KEY | 參數代號 |
| v | TEXT | 參數值 |

## sys_company　單位設定（單一公司）

| 欄位 | 型別 | 說明 |
|---|---|---|
| id | INT NOT NULL PRIMARY KEY | 固定 1 |
| name | VARCHAR(120) NOT NULL DEFAULT '' | 公司、學校或工作室名稱 |
| default_printer | VARCHAR(20) NOT NULL DEFAULT 'A1' | 預設印表機型號（檢查列印範圍用） |
| default_material | VARCHAR(20) NOT NULL DEFAULT 'PLA' | 預設耗材 |
| export_dir | VARCHAR(255) NOT NULL DEFAULT '' | 匯出資料夾（空白＝文件D列印AI代理人） |

## sys_user　使用者

| 欄位 | 型別 | 說明 |
|---|---|---|
| uid | VARCHAR(30) NOT NULL PRIMARY KEY | 帳號 |
| name | VARCHAR(60) NOT NULL | 姓名 |
| pw_hash | VARCHAR(200) NOT NULL | 密碼雜湊（PBKDF2） |
| role | VARCHAR(30) NOT NULL DEFAULT '' | 角色範本 |
| dept | VARCHAR(30) NOT NULL DEFAULT '' | 班別或部門 |
| is_admin | TINYINT NOT NULL DEFAULT 0 | 系統管理員 |
| active | TINYINT NOT NULL DEFAULT 1 | 啟用 |
| last_login | DATETIME NULL | 最近登入 |
| created_at | DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP | 建立時間 |

## sys_user_perm　使用者權限

| 欄位 | 型別 | 說明 |
|---|---|---|
| uid | VARCHAR(30) NOT NULL | 帳號 |
| func | VARCHAR(10) NOT NULL | 功能代號 |
| lvl | TINYINT NOT NULL DEFAULT 0 | 等級 0 無、1 查詢、2 維護 |

索引／鍵：PRIMARY KEY (uid, func)

## sys_audit_log　操作紀錄

| 欄位 | 型別 | 說明 |
|---|---|---|
| id | BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY | 流水號 |
| at | DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP | 時間 |
| uid | VARCHAR(30) NOT NULL DEFAULT '' | 使用者 |
| action | VARCHAR(30) NOT NULL | 動作 |
| target | VARCHAR(80) NOT NULL DEFAULT '' | 對象 |
| detail | TEXT | 內容（異動前 → 後） |

索引／鍵：KEY ix_at (at)

## pa_design　設計（每個要列印的東西一筆）

| 欄位 | 型別 | 說明 |
|---|---|---|
| id | INT NOT NULL AUTO_INCREMENT PRIMARY KEY | 設計編號 |
| title | VARCHAR(120) NOT NULL | 名稱 |
| kind | VARCHAR(8) NOT NULL DEFAULT 'RECIPE' | 來源：RECIPE 參數化零件、FILE 匯入檔案、AI 生成、AGENT 代理人 |
| recipe_id | VARCHAR(30) NOT NULL DEFAULT '' | 參數化零件種類 |
| category | VARCHAR(30) NOT NULL DEFAULT '' | 分類 |
| owner | VARCHAR(30) NOT NULL DEFAULT '' | 建立人 |
| status | VARCHAR(8) NOT NULL DEFAULT 'DRAFT' | DRAFT 草稿、APPROVED 已核准（檔案凍結，雜湊不可變）、PRINTED 已列印、VOID 作廢 |
| cur_rev | INT NOT NULL DEFAULT 0 | 目前版本 |
| printer | VARCHAR(20) NOT NULL DEFAULT '' | 目標印表機 |
| material | VARCHAR(20) NOT NULL DEFAULT '' | 耗材 |
| score | DECIMAL(4,1) NULL | 最近一次列印前檢查分數（滿分 10） |
| size_mm | VARCHAR(60) NOT NULL DEFAULT '' | 尺寸 X×Y×Z |
| weight_g | DECIMAL(9,1) NULL | 估計耗材重量 |
| note | TEXT | 備註 |
| thumb | MEDIUMBLOB | 縮圖 PNG |
| approved_by | VARCHAR(30) NOT NULL DEFAULT '' | 核准人 |
| approved_at | DATETIME NULL | 核准時間 |
| created_at | DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP | 建立時間 |
| updated_at | DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新時間 |

索引／鍵：KEY ix_owner (owner)；KEY ix_status (status)

## pa_revision　設計版本（每次修改存一版，檔案與 SHA-256 一起保存）

| 欄位 | 型別 | 說明 |
|---|---|---|
| design_id | INT NOT NULL | 設計編號 |
| rev | INT NOT NULL | 版本 |
| params | TEXT | 參數（JSON） |
| change_note | VARCHAR(200) NOT NULL DEFAULT '' | 修改說明 |
| file_name | VARCHAR(160) NOT NULL DEFAULT '' | 檔名 |
| file_ext | VARCHAR(8) NOT NULL DEFAULT '.3mf' | 副檔名 |
| file_size | INT NOT NULL DEFAULT 0 | 檔案大小（bytes） |
| file_sha256 | CHAR(64) NOT NULL DEFAULT '' | 檔案 SHA-256（核准後用來確認檔案沒被改過） |
| file_data | LONGBLOB | 檔案內容（zlib 壓縮） |
| check_json | MEDIUMTEXT | 列印前檢查結果（JSON） |
| score | DECIMAL(4,1) NULL | 檢查分數 |
| created_by | VARCHAR(30) NOT NULL DEFAULT '' | 建立人 |
| created_at | DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP | 建立時間 |

索引／鍵：PRIMARY KEY (design_id, rev)

## pa_slice　切片估算紀錄

| 欄位 | 型別 | 說明 |
|---|---|---|
| id | INT NOT NULL AUTO_INCREMENT PRIMARY KEY | 流水號 |
| design_id | INT NOT NULL | 設計編號 |
| rev | INT NOT NULL | 版本 |
| printer | VARCHAR(20) NOT NULL | 印表機 |
| material | VARCHAR(20) NOT NULL | 耗材 |
| quality | VARCHAR(10) NOT NULL DEFAULT 'standard' | draft、standard、fine |
| print_s | INT NOT NULL DEFAULT 0 | 列印秒數（含開始程序） |
| grams | DECIMAL(9,2) NOT NULL DEFAULT 0 | 耗材克數 |
| profile | VARCHAR(120) NOT NULL DEFAULT '' | Bambu Studio 列印設定檔 |
| at | DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP | 時間 |
| uid | VARCHAR(30) NOT NULL DEFAULT '' | 使用者 |

索引／鍵：KEY ix_design (design_id)

## pa_chat　AI 代理人對話

| 欄位 | 型別 | 說明 |
|---|---|---|
| id | INT NOT NULL AUTO_INCREMENT PRIMARY KEY | 對話編號 |
| uid | VARCHAR(30) NOT NULL | 使用者 |
| title | VARCHAR(120) NOT NULL DEFAULT '' | 標題（第一句話） |
| design_id | INT NULL | 對話中存成的設計 |
| engine | VARCHAR(10) NOT NULL DEFAULT 'LOCAL' | CLAUDE 或 LOCAL（本機規則） |
| raw | MEDIUMTEXT | Claude 對話完整歷史（JSON，續聊用） |
| created_at | DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP | 建立時間 |
| updated_at | DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新時間 |

索引／鍵：KEY ix_uid (uid, updated_at)

## pa_chat_msg　AI 代理人對話訊息

| 欄位 | 型別 | 說明 |
|---|---|---|
| chat_id | INT NOT NULL | 對話編號 |
| seq | INT NOT NULL | 順序 |
| role | VARCHAR(10) NOT NULL | user 或 agent |
| text | MEDIUMTEXT | 內容 |
| tools | VARCHAR(255) NOT NULL DEFAULT '' | 這次用到的工具 |
| at | DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP | 時間 |

索引／鍵：PRIMARY KEY (chat_id, seq)

## pa_printer　印表機（區網唯讀連線；存取碼只存在本機，不進資料庫）

| 欄位 | 型別 | 說明 |
|---|---|---|
| id | INT NOT NULL AUTO_INCREMENT PRIMARY KEY | 流水號 |
| name | VARCHAR(60) NOT NULL | 名稱 |
| model | VARCHAR(20) NOT NULL | 型號 |
| ip | VARCHAR(45) NOT NULL DEFAULT '' | 區網 IP |
| serial | VARCHAR(40) NOT NULL DEFAULT '' | 序號 |
| is_default | TINYINT NOT NULL DEFAULT 0 | 預設 |
| note | VARCHAR(200) NOT NULL DEFAULT '' | 備註 |
| created_at | DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP | 建立時間 |
